# SmartCare AI Cost Estimator

**Live demo:** https://nathanhutton-design.github.io/Smart-Care-AI-v3/

## Problem

Uninsured and underinsured patients in the NY/NJ/CT tri-state area often don't know what a procedure will cost until after receiving care, and many aren't aware of free or low-cost programs that could cover or reduce that cost.

## Solution

A cost estimator that takes a patient's insurance coverage tier, procedure type, and in-/out-of-network status, then returns an AI-assisted cost prediction with a transparent, line-by-line pricing breakdown — paired with a searchable directory of 52 verified free and low-cost care programs across the tri-state area.

## Key Features

- Cost estimate calculator (coverage tier: Premium/Standard/Basic/Uninsured, procedure type, network status)
- AI cost predictions with savings insights
- Transparent, line-item pricing breakdown for every estimate
- Searchable database of 52 verified programs across 10 categories — government programs, community health centers, hospital financial aid, free & charitable clinics, patient assistance programs, drug discount cards, generic drugs, loan/financial aid, mental health, and dental/vision

## Tech Stack

- Frontend: HTML/CSS/JavaScript
- AI: Anthropic Claude API for cost predictions
- Backend: PostgreSQL (program directory data, imported from CSV)
- Hosting: GitHub Pages
