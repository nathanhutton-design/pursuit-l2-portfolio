# Helpdesk Ticketing App

**Live demo:** https://nathanhutton-design.github.io/-Helpdesk-Ticket-1-/

## Problem

Small teams or individuals often don't have (or need) a full ServiceNow instance just to log and track support requests, but still want the basics: a ticket queue, status tracking, and a simple intake form.

## Solution

A standalone, browser-based helpdesk ticketing dashboard modeled after ServiceNow's core ticketing workflow — create a ticket, assign it a department and status, and filter the queue by status.

## Key Features

- Ticket dashboard with live ticket count
- New ticket form with validated fields: first/last name, contact number (7–15 digits), department, issue title, description, and status
- Status filter: All Tickets / Open / In Progress / Closed
- Lightweight, dependency-free UI

## Tech Stack

- Frontend: HTML/CSS/JavaScript (client-side only)
